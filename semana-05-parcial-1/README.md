# Parcial 1 - MVC y Frameworks

Esta carpeta contiene el material del primer parcial del curso Desarrollo Web II.

## Contenido

- `spec-parcial-1.md`: especificacion completa del examen, incluyendo alcance, formato, temas y criterios de evaluacion.

## Temas evaluados

- Concepto de patron MVC (Model-View-Controller)
- Componentes del MVC y como interactuan
- Separacion de responsabilidades en aplicaciones web
- Caracteristicas, ventajas y limitaciones de frameworks de desarrollo web
- Comparacion entre frameworks populares
