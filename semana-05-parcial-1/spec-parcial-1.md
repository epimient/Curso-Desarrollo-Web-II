# Parcial 1 — MVC y Frameworks

**Semana 5** | 7 al 13 de sep.

## Alcance

- Concepto de patrón MVC (Model-View-Controller)
- Componentes del MVC y cómo interactúan
- Separación de responsabilidades en aplicaciones web
- Características, ventajas y limitaciones de frameworks de desarrollo web
- Comparación entre frameworks populares

## Temas evaluados

| Tema | Peso | Detalle |
|------|------|---------|
| MVC concepto | 30% | Definición, componentes, flujo de datos |
| MVC en la práctica | 25% | Separación de capas, organización de código |
| Frameworks web | 25% | Concepto, características, comparación |
| Elección de framework | 20% | Criterios de selección, justificación |

## Formato del examen

- **Duración:** 90 minutos
- **Tipo:** Teórico-práctico
- **Puntaje:** 100 puntos

### Parte teórica (50 pts)

1. Diagrama del MVC con explicación de cada componente (15 pts)
2. Tabla comparativa de al menos 3 frameworks web (15 pts)
3. Ventajas y limitaciones de usar un framework vs código puro (20 pts)

### Parte práctica (50 pts)

1. Dado un código monolítico, identificar los componentes MVC y proponer separación (25 pts)
2. Seleccionar un framework para un caso de uso específico y justificar la decisión (25 pts)

## Material de estudio

- Clases 01-04 (semanas 01-04)
- Ejemplos guiados de MVC y comparación de frameworks
- Ejercicios de separación de responsabilidades

## Criterios de evaluación

- Claridad en la definición de conceptos MVC
- Capacidad de identificar componentes en código existente
- Argumentación sólida en la selección de frameworks
- Uso correcto de terminología técnica
