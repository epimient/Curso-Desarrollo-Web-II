# Clase 03 - Separacion de responsabilidades

Esta carpeta contiene la tercera clase del curso Desarrollo Web II con enfoque en FastAPI.

## Estructura

- `clase-03.md`: documento principal de la clase, con explicacion de separacion de responsabilidades y organizacion de aplicaciones web mediante MVC.
- `html/index.html`: diapositivas de apoyo para proyectar en clase.
- `dudas/preguntas-frecuentes.md`: banco de preguntas y aclaraciones.
- `ejercicios/ejercicios-clase-03.md`: ejercicios de practica y reflexion.
- `ejemplo-guiado/`: ejemplo paso a paso de separacion de capas.

## Uso sugerido

1. Leer `clase-03.md` como guia docente principal.
2. Abrir `html/index.html` en el navegador para usar las diapositivas.
3. Aplicar los ejercicios de separacion de responsabilidades.
4. Usar el ejemplo guiado para practicar la refactorizacion de codigo monolitico a capas.
