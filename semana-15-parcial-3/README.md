# Parcial 3 - FastAPI Completo

Esta carpeta contiene el material del tercer parcial del curso Desarrollo Web II.

## Contenido

- `spec-parcial-3.md`: especificacion completa del examen, incluyendo alcance, formato, temas y criterios de evaluacion.

## Temas evaluados

- Creacion y manejo de rutas (APIRouter)
- Routers como equivalente MVC de controladores
- Dependency injection y manejo de solicitudes
- Integracion con SQLAlchemy (persistencia)
- Testing con pytest y TestClient
