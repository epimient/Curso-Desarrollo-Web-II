# Clase 13 - Routers, logica de negocio y SQLAlchemy

Esta carpeta contiene la decimotercera clase del curso Desarrollo Web II con enfoque en FastAPI.

## Estructura

- `clase-07-persistencia-sqlalchemy.md`: documento principal sobre persistencia con SQLAlchemy.
- `clase-08-relaciones-sqlalchemy.md`: documento sobre relaciones entre modelos SQLAlchemy.
- `html/index.html`: diapositivas de apoyo para proyectar en clase.
- `html/index-relaciones.html`: diapositivas sobre relaciones.
- `dudas/preguntas-frecuentes.md`: banco de preguntas y aclaraciones.
- `dudas/preguntas-frecuentes-relaciones.md`: preguntas frecuentes sobre relaciones.
- `ejercicios/ejercicios-clase-07.md`: ejercicios de persistencia.
- `ejercicios/ejercicios-clase-08.md`: ejercicios de relaciones.
- `ejemplo-guiado/`: ejemplos de persistencia y relaciones con SQLAlchemy.

## Uso sugerido

1. Leer `clase-07-persistencia-sqlalchemy.md` como guia principal.
2. Leer `clase-08-relaciones-sqlalchemy.md` para relaciones.
3. Abrir `html/index.html` para las diapositivas.
4. Aplicar los ejercicios de persistencia y relaciones.
5. Usar los ejemplos guiados para practicar CRUD con SQLAlchemy.
