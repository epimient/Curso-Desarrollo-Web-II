Que es un programa?

Una serie de instrucciones que una computadora ejecuta.

print("Hola mundo")

El programa recibe una instruccion y produce un resultado.

Que es Python?

El idioma que utilizaremos para darle instrucciones al computador.

print("Hola mundo")       # Python
Console.WriteLine(...)    # C#
System.out.println(...)   # Java

Python reduce el ruido sintactico.

Variables y tipos

nombre = "Ana"       # str
edad = 20            # int
altura = 1.68        # float
activo = True        # bool

Python determina el tipo automaticamente (tipado dinamico).

Diccionarios

estudiante = {
    "nombre": "Ana",
    "edad": 20
}

Clave → Valor. Muy parecido a JSON.

Que es JSON?

JavaScript Object Notation — formato para intercambiar datos.

Python

{"nombre": "Ana"}

JSON

{"nombre": "Ana"}

Funciones

def sumar(a, b):
    return a + b

print(sumar(10, 20))  # 30

Una ruta de FastAPI es basicamente una funcion Python.

Nuestra primera app

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def inicio():
    return {"mensaje": "Hola mundo"}

Cuando alguien haga GET a /, ejecuta inicio().
