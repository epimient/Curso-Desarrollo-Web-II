# Clase 00 — Introduccion a Python, APIs y FastAPI

Esta carpeta contiene la clase pre-requisito del curso Desarrollo Web II.

## Estructura

- `clase-00.md`: documento principal de la clase, con introduccion completa a Python, HTTP, APIs y FastAPI.
- `html/index.html`: diapositivas de apoyo para proyectar en clase (15 slides).
- `ejemplo-guiado/api-videojuegos.md`: tutorial paso a paso para crear una API de videojuegos.
- `ejemplo-guiado/proyecto-videojuegos/`: codigo fuente funcional (main.py + requirements.txt).
- `ejercicios/ejercicios-clase-00.md`: ejercicios de practica (6 ejercicios progresivos).
- `dudas/preguntas-frecuentes.md`: banco de preguntas y aclaraciones.

## Uso sugerido

1. Leer `clase-00.md` como guia docente principal.
2. Abrir `html/index.html` en el navegador para usar las diapositivas.
3. Aplicar los ejercicios durante la clase o como practica independiente.
4. Usar el ejemplo guiado para conectar Python con FastAPI por primera vez.

## Pre-requisitos

- Python 3.10+ instalado
- Conocimientos basicos de programacion (variables, funciones)
- Un editor de codigo (VS Code recomendado)
