Rendimiento

FastAPI es uno de los frameworks mas rapidos de Python:

Flask

~1,000 req/s

FastAPI

~12,000+ req/s

Validacion con Pydantic

class CursoCreate(BaseModel):
    nombre: str = Field(..., min_length=1)
    creditos: int = Field(..., gt=0, le=10)

Si alguien envia creditos: -5, FastAPI rechaza automaticamente.

Documentacion automatica

Swagger UI

http://localhost:8000/docs

ReDoc

Decision final

FastAPI es la mejor opcion para el curso porque:

  • Enfoque en APIs REST
  • Velocidad y modernidad
  • Documentacion automatica
  • Validacion con Pydantic
  • Soporte nativo para async
