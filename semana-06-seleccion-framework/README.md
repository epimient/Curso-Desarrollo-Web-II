# Clase 06 - Seleccion de un framework especifico

Esta carpeta contiene la sexta clase del curso Desarrollo Web II con enfoque en FastAPI.

## Estructura

- `clase-06.md`: documento principal de la clase, con justificacion tecnica de la seleccion de FastAPI como framework del curso.
- `html/index.html`: diapositivas de apoyo para proyectar en clase.
- `dudas/preguntas-frecuentes.md`: banco de preguntas y aclaraciones.
- `ejercicios/ejercicios-clase-06.md`: ejercicios de practica y reflexion.
- `ejemplo-guiado/`: ejemplo de instalacion y verificacion de FastAPI.

## Uso sugerido

1. Leer `clase-06.md` como guia docente principal.
2. Abrir `html/index.html` en el navegador para usar las diapositivas.
3. Aplicar los ejercicios de instalacion y configuracion.
4. Usar el ejemplo guiado para verificar que FastAPI funciona correctamente.
