# Clase 06 - Seleccion de un framework especifico (FastAPI)

Esta carpeta contiene el material completo de la sexta clase del curso **Desarrollo Web II** con enfoque en **FastAPI**.

## 📁 Estructura del Módulo

- `clase-06.md`: Documento principal de la clase, con justificación técnica de la selección de FastAPI como framework del curso.
- `html/index.html`: Diapositivas interactivas de apoyo para proyectar en clase.
- `dudas/preguntas-frecuentes.md`: Banco de preguntas frecuentes y aclaraciones para los estudiantes.
- `ejercicios/ejercicios-clase-06.md`: Ejercicios de práctica, reflexión y modelado Pydantic.
- `ejemplo-guiado/api-pqrs/`: Proyecto FastAPI funcional con la API de PQRS (Peticiones, Quejas, Reclamos y Sugerencias).

## 🚀 Uso Sugerido

1. Leer `clase-06.md` como guía docente principal.
2. Abrir `html/index.html` en el navegador para proyectar las diapositivas.
3. Revisar `dudas/preguntas-frecuentes.md` para preparar la resolución de inquietudes comunes.
4. Explorar y ejecutar el ejemplo guiado en `ejemplo-guiado/api-pqrs/` comprobando la documentación interactiva en `/docs`.
5. Aplicar los ejercicios prácticos planteados en `ejercicios/ejercicios-clase-06.md`.
