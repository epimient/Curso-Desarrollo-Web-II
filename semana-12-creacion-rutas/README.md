# Clase 12 - Creacion y manejo de rutas

Esta carpeta contiene la duodecima clase del curso Desarrollo Web II con enfoque en FastAPI.

## Estructura

- `clase-12.md`: documento principal de la clase, con explicacion de APIRouter, path params, query params y HTTP methods.
- `html/index.html`: diapositivas de apoyo para proyectar en clase.
- `dudas/preguntas-frecuentes.md`: banco de preguntas y aclaraciones.
- `ejercicios/ejercicios-clase-12.md`: ejercicios de practica y reflexion.
- `ejemplo-guiado/`: ejemplo de CRUD completo con rutas.

## Uso sugerido

1. Leer `clase-12.md` como guia docente principal.
2. Abrir `html/index.html` en el navegador para usar las diapositivas.
3. Aplicar los ejercicios de creacion de rutas.
4. Usar el ejemplo guiado para practicar el manejo de rutas en FastAPI.
