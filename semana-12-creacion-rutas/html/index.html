Creacion y manejo de rutas

APIRouter, path params, query params, HTTP methods

Ing. Eduardo Pimienta — Desarrollo Web II

APIRouter

Organiza las rutas por modulos, como carpetas de archivos.

router = APIRouter(prefix="/courses", tags=["courses"])

@router.get("/")
def list_courses():
    return []

Path Parameters

Datos que van directo en la URL:

@router.get("/{course_id}")
def get_course(course_id: int):
    return {"id": course_id}

/courses/5 → course_id = 5

Query Parameters

Datos despues del ? en la URL:

@router.get("/")
def list_courses(page: int = 1, limit: int = 10):
    return {"page": page, "limit": limit}

/courses?page=2&limit=5

Resumen

  • APIRouter organiza las rutas por modulos
  • Path params van en la URL
  • Query params van despues del ?
  • Cada metodo HTTP tiene un proposito
  • Los status codes comunican el resultado
